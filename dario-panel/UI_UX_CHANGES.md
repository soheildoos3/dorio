# بهبود UI/UX و ریسپانسیو پنل Dario

این نسخه روی خوانایی، سرعت انجام کار، استفاده روی موبایل/تبلت و یکدست شدن تجربه کاربری تمرکز دارد.

## تغییرات اصلی
- بازطراحی سایدبار و منوی موبایل با گروه‌بندی واضح‌تر بخش‌ها.
- بهبود Topbar، عنوان صفحات و جستجوی بخش‌های مجاز پنل.
- بهبود نمایش در موبایل با Safe Area، فاصله‌گذاری responsive و جلوگیری از شکستن Layout.
- بازطراحی Button، Badge، Field، Switch، Tabs، Card و Modal.
- پشتیبانی واقعی از `size="sm"` در Button و اضافه شدن tone `gray` در Badge.
- مودال‌های مناسب موبایل با اسکرول داخلی، Escape، بازگردانی Focus و Header ثابت.
- بهبود جدول‌های بزرگ برای صفحه‌های داده‌محور و اسکرول افقی کنترل‌شده در موبایل.
- بازطراحی صفحه ورود و داشبورد.
- بهبود صفحه گارانتی با جستجو، فیلتر وضعیت، کارت‌های آماری کلیک‌پذیر و حالت‌های Loading/Error/Empty.
- بهبود چیدمان موبایل در صفحه کنترل کیفیت و اکشن‌های چاپ QR.
- رعایت focus-visible، reduced-motion و جلوگیری از Zoom ناخواسته iOS روی فرم‌ها.

## بررسی انجام‌شده
- همه 43 فایل TypeScript/TSX با TypeScript `transpileModule` از نظر Syntax بررسی شده‌اند و خطای Syntax ندارند.
- Build کامل در محیط فعلی اجرا نشد، چون dependencyهای `node_modules` همراه ZIP موجود نبودند و نصب شبکه‌ای محیط کامل نشد. سورس و package files دست‌نخورده و آماده `npm install` / `npm ci` در محیط توسعه هستند.
