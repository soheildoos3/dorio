# Dario Panel v3

React + TypeScript + Tailwind CSS 4. این پروژه از Backend جدا است و فقط از API آن استفاده می‌کند.

## توسعه

```powershell
Copy-Item .env.example .env
npm ci
npm run dev
```

پنل روی `0.0.0.0:5173` بالا می‌آید. در توسعه Vite درخواست‌های `/api` و `/media` را به `VITE_BACKEND_TARGET` proxy می‌کند.

برای دسترسی از سیستم دوم روی همان Wi-Fi، Backend و Panel را روی `0.0.0.0` اجرا کنید و IP سیستم میزبان را باز کنید، مثل `http://192.168.1.3:5173`.

## UX

- شناسه‌های داخلی دیتابیس در فرم‌های روزمره از اپراتور درخواست نمی‌شوند.
- کالا با نام محصول، ویژگی‌های Variant، شماره گارانتی، قفس و مرجع سفارش انتخاب می‌شود.
- SKU و سریال داخلی اختیاری هستند.
- شماره گارانتی و شماره اسناد عملیاتی خودکارند.
- تاریخ‌های نمایشی با `fa-IR-u-ca-persian` شمسی نمایش داده می‌شوند.
- گالری صفحه محصول اسلاید/thumbnail و فیلتر تصاویر هر Variant دارد.
- کاربران، کارمندان، خیاط‌ها و مشتری‌ها یک هویت واحد دارند؛ صفحه خیاط‌ها فقط داشبورد عملیاتی و KPI است.
- منو و عملیات بر اساس permission کاربر نمایش داده می‌شوند؛ Backend هم permission را مستقل enforce می‌کند.
